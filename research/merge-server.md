Ticket: frappe/frappe#45481. Map: frappe/frappe#45480 (ruling 3: with `enable_desk_v2` off, desk v1's UI and APIs do not change; new tables, DocTypes and endpoints are allowed; a shared-code refactor needs a test that shows v1 gets the same output).

## Method

- Range: `b9e4d35824` (`git merge-base upstream/develop upstream/desk-v2`) to `upstream/desk-v2` at `8c96392df6`.
- Source: `git diff` of every modified Python, JSON and hook file. Added files are listed only when a hook, a shared module or a route that v1 reaches loads them.
- Skipped: `frontend/`, `ui/` (the `@framework/ui` package; client code), `frappe/shell/` except the parts that hooks call, and new DocTypes that nothing else reads (Rail, Doctype View, Favourite, Form Layout, Settings Dialog/Pane/Block, Navigation Item, Navigation Item Type).
- Line numbers point into `upstream/desk-v2`.
- The setting is read in three places only: `ShellPage.can_render`/`render` (`frappe/website/page_renderers/shell_page.py:56`, `:61`), `get_url_to_form` (`frappe/utils/data.py:2157`) and the v1 user menu (`frappe/public/js/frappe/ui/sidebar/sidebar.js:452`). Every other row below runs with the setting off.
- "Keep*" means keep, but ruling 3 needs a parity test that does not exist yet.

## Summary

- **Rows:** 42. **Keep:** 36, and 5 of these (rows 9, 12, 15, 18, 19) need a new parity test under ruling 3. **Gate:** 1. **Fix:** 5.
- **Gated by the setting:** only rows 5 (in part), 28 and 41 (sidebar.js). All other rows run with desk v2 off.
- **No patches.** A v1 site that migrates gets: the Sidebar `title` unique index dropped, three new Sidebar columns and a composite unique index, `Client Script.run_order`, `System Settings.enable_desk_v2`, a Route History index, and the new DocTypes. No test migrates from the merge-base schema.

### Riskiest items

1. **Row 11, Text Editor auto-attach (gate).** It runs on every save in a request. It can attach a user's standalone File to a doc, so the File is deleted with that doc. It can also make a private File public. It takes a row lock on File.
2. **Row 33, Data Import `start_import` (fix).** A new whitelisted doc method that checks read only, while the v1 path checks write.
3. **Row 22, Contact flat values (fix).** It silently changes what a v1 API insert stores.
4. **Row 21, tag removal through `delete_doc` (fix).** It costs about 10 times more per removed tag, and every app's `"*" on_trash` hooks now see Tag Link deletes.
5. **Rows 24 and 25, Client Script and Sidebar forms (fix).** v1 users see v2 options and fields. Row 25 also moves Sidebar title uniqueness from the database into the controller.
6. **Row 16, activity timeline (keep, owner nod).** The response shape changes and two whitelisted methods are removed. Desk v1 does not call them; `@framework/ui` and Studio do, and they change in the same build.
7. **Rows 3 and 5, install prefix guard and `/apps` (keep under ruling 5).** An install can now be refused. `/apps/<x>` is now a 404 for every site.
